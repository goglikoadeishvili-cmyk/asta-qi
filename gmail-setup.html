შენი Gmail-იდან პირდაპირ გაგზავნა

ერთჯერადი კონფიგურაციის შემდეგ აპში „Connect Gmail“-ს დააჭერ და შენს ანგარიშს აირჩევ. შემდეგ მიმღებს მიუთითებ და ერთი ZIP ერთ წერილად გაიგზავნება.

  1. გახსენი Google Cloud Console შენი გამგზავნი Gmail-ით და შექმენი პროექტი ASTA QI.
  2. APIs & Services → Library: ჩართე Gmail API და, ტელეფონსა და ლეპტოპს შორის სინქრონიზაციისთვის, Google Drive API.
  3. Google Auth Platform-ში შეავსე Branding, Audience — External. პირადი გამოყენებისთვის Testing რეჟიმში დაამატე შენი Gmail როგორც Test user. მოითხოვე მხოლოდ https://www.googleapis.com/auth/gmail.send, openid და email. სინქრონიზაციისთვის ასევე დაამატე https://www.googleapis.com/auth/drive.appdata.
  4. Clients → Create client → Web application. Authorized JavaScript origins-ში ჩაწერე ზუსტად https://goglikoadeishvili-cmyk.github.io — ბოლოს /asta-qi/ არ დაამატო.
  5. დააკოპირე Client ID, რომელიც მთავრდება .apps.googleusercontent.com-ით. აპში გახსენი Projects → Backup & app settings → Company & email. ჩასვი Client ID და გამგზავნის მისამართი goglikoadeishvili@gmail.com, შემდეგ Save settings.
  6. მონიშნე დასრულებული ინსპექციები → Generate PDFs & Send Email → Connect Gmail → შენი ანგარიში → გაგზავნის ნებართვა. შეავსე To — recipient email და დააჭირე Send one email from Gmail.

ტელეფონი ↔ ლეპტოპი: ორივე მოწყობილობაში ჩასვი ზუსტად იგივე Client ID და გამოიყენე იგივე Google ანგარიში. აპის ქვედა ნაწილში გახსენი Phone ↔ laptop sync და დააჭირე Connect private cloud sync. Google-ის ნებართვის შემდეგ პირველი სინქრონიზაცია ატვირთავს ამ მოწყობილობაზე არსებულ ჩანაწერებს და ჩამოტვირთავს მეორე მოწყობილობის მონაცემებს. გადატანა არ წაშლის ადგილობრივ ორიგინალებს. ავტომატური სინქრონიზაცია მუშაობს ყოველ 30 წამში, სანამ აპი გახსნილია და ანგარიში დაკავშირებულია. ავტორიზაციის ვადის გასვლისას ხელახლა Connect იქნება საჭირო.

პაროლი, Client secret ან App password არ ჩაწერო აპში და არ გამომიგზავნო. Client ID საჯარო იდენტიფიკატორია. დროებითი წვდომის ტოკენი მხოლოდ ღია აპის მეხსიერებაში რჩება და არც სარეზერვო ფაილში, არც GitHub-ში არ ინახება.

Google-ის Testing რეჟიმს აქვს მომხმარებლების/ავტორიზაციის შეზღუდვები; ხელახლა დაკავშირება შეიძლება მოგთხოვოს. Google-ის მიერ დაბლოკილი ავტორიზაცია არ უნდა შემოვუაროთ — ჯერ კონფიგურაცია უნდა გასწორდეს.

Delivered ინიშნება მხოლოდ მიმღების მიღების დადასტურების შენ მიერ ჩაწერის შემდეგ; Gmail-ის Send პასუხი მიწოდებას არ ადასტურებს. დადასტურებიდან 7 დღეში შესაბამისი ინსპექციის ვერსია გადავა აღდგენად არქივში, აპის გახსნისას ან გახსნილ აპში შემოწმების დროს. QA ჩანაწერები, პინები, ფოტოები და გაგზავნილი PDF-ები ინახება; არქივირება სივრცეს არ ათავისუფლებს. მუდმივი, ფონური სერვერული წაშლა არ არის ჩართული.

აპი წერილს გაგზავნილად მხოლოდ Gmail-ის წარმატებული პასუხისა და Message ID-ის შემდეგ აღნიშნავს. ეს მიმღების მიერ მიღების ან წაკითხვის დადასტურება არ არის. გაურკვეველი პასუხისას ჯერ Gmail-ის Sent შეამოწმე; ავტომატური განმეორებითი გაგზავნა არ ხდება.

ამ აპის ZIP დანართის ლიმიტია 24 MB. დიდი ZIP-ის შემთხვევაში ფოტოებს ხარისხს არ ვუკლებთ: აირჩიე ნაკლები ინსპექცია ან ცალკე კონფიგურირებული დაცული ბმულის gateway. აპი Google Drive ბმულს ავტომატურად არ ქმნის.
